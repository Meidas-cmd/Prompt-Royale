# Skill: Generación de Elementos con Angular CLI

Cuando el usuario te pida crear nuevos componentes, servicios o guardias, proporciona el comando de terminal exacto teniendo en cuenta que trabajamos en la subcarpeta `/App/frontend`:

1. **Generar Componente Standalone:** `ng g c components/nombre-componente`
2. **Generar Servicio API (Observables):** `ng g s services/nombre-servicio`
3. **Recordatorio Estructural:** Los comandos de generación deben lanzarse siempre asegurando que el usuario está posicionado en la raíz de la aplicación frontend (`/App/frontend`).
